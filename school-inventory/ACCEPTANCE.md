# Проверка перед использованием

Ни один пункт ниже не был исполнен в среде создания архива. Используйте отдельную тестовую БД.

## Сборка
- npm install; prisma generate; npm run typecheck; npm run test; npm run build.
- Проверить npm audit и версии Next/React по актуальным рекомендациям.
- Проверить запуск Docker, seed и повторный seed.

## Права
- Создать IT-оператора, завхоза, VIEWER ALL.
- IT не видит мебель HOUSEHOLD; завхоз не видит IT, помещения общие.
- Подставить чужой ID в move, document, receive, check, plan: операция отклоняется.
- VIEWER не меняет записи даже прямым POST.
- Без входа закрыты API, Excel, планы, акты, QR-страницы.
- Origin с другого домена отклоняется для POST.
- Отключить пользователя: старая сессия перестаёт работать.

## Учёт
- Создать объект с номером 000001: нули сохранены.
- Дубликат внутри школы не создаётся.
- Перемещение сохраняет откуда/куда и пользователя.
- Создать черновик: объект остаётся активным.
- Провести: объект в архиве, повторное проведение отклоняется.
- Два черновика с одним объектом: провести можно только один.
- Отмена проведённого акта администратором возвращает объект, записывает причину.
- Материал 10 шт по 100 рублей; списать 3: осталось 7, сумма акта 300.
- Два параллельных списания сверх остатка: одно отклоняется; отрицательного остатка нет.
- Перемещение партии сохраняет количество в сумме и цену.
- Нельзя списать отрицательное количество или количество с >3 знаками после запятой.

## Excel и карта
- Проверить текстовые номера, запятую в цене, пустые поля, дубликаты, неизвестное помещение, разные листы.
- При ошибках commit не импортирует часть строк.
- Проверить необязательные несопоставленные колонки.
- Загрузить PNG и JPEG; SVG, HTML и исполняемый файл отклоняются.
- Нарисовать многоугольник, сохранить, перезагрузить, открыть кабинет, проверить на телефоне.

## Инвентаризация и печать
- Создать снимок, отметить объект на месте и в другом помещении; учётное место не меняется.
- Закрытую проверку нельзя редактировать.
- QR открывает только доступную карточку; новый пользователь сначала входит.
- Акт показывает исходные строки, номер, дату, итог, отметку черновика/отмены.
- Проверьте печать на реальном принтере и в PDF.

## Восстановление
- Сделать копию базы и файлов; восстановить в отдельную установку.
- Проверить вход, карты, остатки, документы и журнал.
