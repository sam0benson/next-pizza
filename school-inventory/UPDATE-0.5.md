# Обновление до 0.5 — вход по Face ID / Touch ID / отпечатку

## Что нового
- **Вход без пароля и без кода 2FA** по Face ID (iPhone/iPad), Touch ID (Mac), отпечатку (Android) или Windows Hello. Технология — passkey (WebAuthn), работает в Safari и в установленном PWA, iOS 16+.
- После обычного входа на телефоне на главной появляется предложение «Входить по Face ID?». Его можно включить или выключить в разделе **Безопасность** → «Вход по Face ID».
- На экране входа появляется кнопка **«Войти по Face ID»**. Она видна только на устройстве, где вход уже включён.
- На ПК и других устройствах всё по-прежнему: пароль и код из приложения.

## Безопасность
- Ключ привязан к **доверенному устройству**, на котором его включили. Это проверяется по cookie устройства. Скопированный через iCloud ключ на Mac или iPad без подтверждённого устройства не сработает.
- Нужна проверка пользователя (Face ID/отпечаток или пароль от телефона). Каждый запрос входа одноразовый и действует 5 минут. Повтор перехваченного ответа и поддельная подпись отклоняются.
- Если администратор **блокирует или удаляет устройство**, ключи этого устройства удаляются. Отключённый пользователь войти не сможет.
- В журнале записываются события «Включён/Отключён вход по Face ID». В разделе «Устройства» есть отметка «вход без пароля».

## Обновление
Ручных команд не нужно. Таблицы `Passkey` и `AuthChallenge` приложение создаёт само при первом запуске (`CREATE TABLE IF NOT EXISTS`). Тот же SQL лежит в `prisma/upgrades/0.5.sql`.

```sh
git add -A
git commit -m "v0.5: вход по Face ID / Touch ID"
git push
```

Для работы нужно, чтобы `APP_ORIGIN` в точности совпадал с адресом сайта (например, `https://invent.vvless.ru`). Домен ключа берётся из него.

После деплоя закройте и снова откройте приложение на телефоне. Войдите один раз по паролю и коду, потом нажмите «Включить» в предложении на главной.
