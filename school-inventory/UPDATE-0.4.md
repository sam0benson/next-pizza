# Версия 0.4: новый дизайн, «нативный» PWA, сканирование для инвентаризации

Миграция базы данных **не нужна** — схема не менялась. Достаточно обновить код и пересобрать образ (GitHub Actions сделает это сам после `git push`).

## Дизайн
- Новая дизайн-система: светлая и **тёмная тема** (Авто / Светлая / Тёмная — в боковой панели, в меню «Ещё» и в разделе «Безопасность»).
- **Компьютер:** боковая панель с иконками и группами разделов (Главное, Учёт, Данные, Администрирование), карточка пользователя и выход внизу, «липкая» верхняя панель с кнопкой «Сканировать QR».
- **Телефон:** верхняя панель приложения и **нижняя панель вкладок** — Обзор, Имущество, большая кнопка «Скан», Проверка, «Ещё» (все остальные разделы, тема, выход). Окна открываются как шторки снизу, кнопки «Сохранить/Отмена» всегда видны. Учтены вырезы экрана (safe area).
- Имущество, документы и ведомость инвентаризации на телефоне показываются списком-карточками вместо широких таблиц.
- Цветные статусы: состояние имущества, статусы актов, результаты проверки.
- Всплывающие уведомления об успешных действиях и ошибках вместо красной полосы вверху.

## PWA без масштабирования
- Страница больше не приближается: ни при фокусе на поле пароля/поиска (поля на телефоне 16 px), ни щипком, ни двойным тапом. В режиме установленного приложения на компьютере отключён и Ctrl + колесо / Ctrl + «+».
- **Карта школы** масштабируется отдельно: щипком двумя пальцами (точка между пальцами остаётся на месте), Ctrl + колесо мыши / жест трекпада, кнопками «−» «+» (до 500 %). В редакторе карты щипок не ставит лишних точек.

## Новые функции
- **Обзор:** приветствие, кликабельные показатели, прогресс текущей инвентаризации с кнопкой «Продолжить сканирование», быстрые действия, блок «Требует внимания» (устройства ждут подтверждения, просроченные выдачи, черновики актов, неисправное имущество, открытые ремонты, материалы ниже минимума) и лента последних действий.
- **Инвентаризация «Сканировать подряд»:** выбираете помещение, где находитесь, и сканируете этикетки одну за другой — каждая отмечается автоматически, окно не закрывается. Сразу видно: «на месте», «числится в другом помещении», «не входит в проверку», «повторно». Вибрация, подсветка рамки, журнал сеанса, защита от двойного срабатывания одной этикетки.
- Ведомость: цветной прогресс, фильтры «Не проверено / На месте / В другом месте / Не найдено», поиск, кнопка «На месте» в одну касание.
- **Сканер:** поиск по инвентарному номеру вручную (если этикетка повреждена), фонарик (если телефон поддерживает).
- **Имущество:** фильтры по категории и состоянию, сортировка (новые, название, инв. номер, стоимость), итог «найдено N на сумму…», «выбрать все», панель действий с выбранными.
- **Карточка объекта:** все поля, включая дополнительные, кнопки «Изменить», «Переместить», «QR-этикетка», история в виде ленты с именами сотрудников.
- **Журнал:** имена пользователей вместо идентификаторов, понятные названия действий, поиск.
- Отчёты с наглядными полосами долей; поиск в помещениях и материалах; индикатор «Нет подключения к сети».
- Закрытие окон клавишей Esc и тапом по затемнению.

## Проверено
- Все действия API (помещения, имущество, перемещения, материалы и партии, ремонты, выдача/возврат, комплекты, акты списания и их отмена, инвентаризация, экспорт XLSX, импорт Excel, вложения, планы этажей, пользователи, перевыпуск QR) — без ошибок.
- Все 16 разделов открываются без ошибок в консоли; E2E-сценарий входа, подтверждения устройства, 2FA, сканера и блокировки — 20/20.

## Обновление
```sh
# в папке репозитория
git add -A
git commit -m "v0.4: новый дизайн, PWA без zoom, сканирование для инвентаризации"
git push
```
После деплоя на телефоне закройте и снова откройте установленное приложение (service worker обновится сам).
