# Car Launcher (заготовка в стиле CC4)

## Что уже сделано
- Главный экран с часами, датой, сеткой из 8 ярлыков и нижней панелью быстрого доступа (Bluetooth, громкость, яркость, все приложения).
- Экран «Все приложения» — сеткой, как в стоковых лаунчерах магнитол.
- Регистрация приложения как замены рабочего стола (HOME) — при установке система предложит сделать его лаунчером по умолчанию.
- Переключение Bluetooth, изменение громкости и яркости экрана прямо с главного экрана.

## Как открыть проект (с нуля, пошагово)

1. Установите **Android Studio** (последнюю стабильную версию) с официального сайта developer.android.com/studio.
2. При первом запуске: **New Project → Empty Views Activity**, язык — **Kotlin**, Minimum SDK — **API 21**. Дайте проекту любое имя, дождитесь синхронизации Gradle.
3. Закройте Android Studio. Скопируйте файлы из этого архива поверх созданного проекта:
   - `app/src/main/AndroidManifest.xml` → замените
   - `app/src/main/java/com/example/cc4launcher/*.kt` → скопируйте в пакет вашего проекта (переименуйте пакет в build.gradle и manifest на свой, либо оставьте `com.example.cc4launcher`)
   - `app/src/main/res/layout/*` → скопируйте все файлы
   - `app/src/main/res/values/*` → замените/объедините
   - `app/src/main/res/drawable/*` → скопируйте все файлы
   - `app/build.gradle` → замените (проверьте, что `namespace` и `applicationId` совпадают с тем, что вы задали при создании проекта)
4. Откройте проект заново в Android Studio, дождитесь Gradle Sync.
5. Подключите магнитолу по USB (включите отладку по USB в настройках Android на магнитоле) или соберите APK через **Build → Build Bundle(s)/APK(s) → Build APK(s)** и установите файл вручную (через USB-флешку или ADB).
6. После установки на магнитоле: **Настройки → Приложения → Выбор по умолчанию → Домашний экран** — выберите ваше приложение.

## Что стоит доработать дальше
- **Иконки**: сейчас везде используется одна и та же простая заглушка. Замените файлы в `res/drawable/ic_*.xml` через **File → New → Vector Asset** в Android Studio — там огромная бесплатная библиотека Material Icons (bluetooth, volume_up, brightness_6, apps, music_note, navigation, phone, radio, directions_car, settings и т.д.), это займёт 10 минут.
- **Виджет погоды**: потребует API-ключ погодного сервиса (например, OpenWeatherMap) и отдельный сетевой запрос — могу помочь добавить отдельным шагом.
- **Автоспецифичные функции** (CarPlay-подобная интеграция с CAN-шиной, задняя камера, эквалайзер) на большинстве магнитол реализованы через системные Intent'ы конкретного производителя платы — их нужно смотреть в документации/прошивке вашей магнитолы, они не универсальны.
- **Внешний вид карточек** — сейчас плоские тёмные прямоугольники; при желании добавьте градиенты, анимации нажатия (`selector` + `ripple`), крупный логотип магнитолы и т.п.

## Дисклеймер
Это не копия проприетарного интерфейса Teyes — это самостоятельно написанный лаунчер с похожей структурой экрана (тёмная тема, плитки, нижняя панель). Все иконки — временные заглушки, замените их для чистоты (см. пункт выше).
